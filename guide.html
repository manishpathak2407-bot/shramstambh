4. Core Mathematical Models & Algorithmic Rationale

A. Daily Wage Khata & Net Balance Due Formula

In js/wageTracker.js and js/app.js: 

Total Wages Earned = Σ (Daily Agreed Wage × Days Worked)
Net Balance Due    = Total Wages Earned - Total Advance Received

This simple, indisputable calculation prevents thekedars from confusing laborers through vague verbal accounts or partial cash deductions.

B. Statutory Wage Theft & Deprivation Formula

Daily Deprivation   = Statutory Legal Rate (State BOCW) - Contractor Offered Rate
Monthly Deprivation = Daily Deprivation × 26 Work Days
Annual Deprivation  = Monthly Deprivation × 12 Months

If Contractor Offered Rate < Statutory Legal Rate, the system triggers the Wage Theft Alert, displays the legal shortfall, and cites the Minimum Wages Act 1948.

5. Master Viva Voce Bank (27 Questions & Word-for-Word Answers)

Q1: Why did you choose pure Vanilla JS over React, Angular, or Vue?
In academic evaluations, students often use React out of habit without considering user constraints. Migrant laborers at construction " "sites operate low-end Android smartphones over congested 2G/3G cellular networks. React adds 140+ KB of runtime overhead and requires a complex " "build step. Vanilla JS boots in under 150ms, consumes minimal battery/RAM, has zero external bundle dependencies (0 KB weight), and runs " "natively in any browser with zero node_modules.
Q2: How is data preserved without a backend server like Node.js or MongoDB?
We leverage the HTML5 Web Storage API (window.localStorage) utilizing structured JSON schema serialization (JSON.stringify / JSON.parse). " "Data persists indefinitely across browser reboots and device restarts. This guarantees Rs. 0 operational server costs and ensures vulnerable " "migrant records are never exposed on remote cloud servers.
Q3: Where did you source the statutory minimum wage rates from?
We extracted official gazette rates published by State Labour Departments and State BOCW Welfare Boards. For example, Delhi NCT's rates " "reflect Notification F.No.12(142)/02/MW/VII. Rates are categorized across 4 skill tiers: Unskilled, Semi-skilled, Skilled, and Highly Skilled.
Q4: How does your application solve worker illiteracy technically?
We integrated the browser's native W3C SpeechSynthesis API in js/speech.js. Rather than requiring external paid APIs that demand internet " "and credit cards, we leverage the device's built-in text-to-speech engine with Indian locales (en-IN / hi-IN). Tapping 'Listen' reads " "summaries aloud instantly with zero external dependencies.
Q5: How does the application guarantee whistleblower anonymity against contractor retaliation?
In js/complaints.js, when 'Keep Identity 100% Anonymous' is checked, client-side sanitization strips user-identifying keys (name, phone, IP) " "before committing to storage. It generates an isolated alphanumeric token (#SH-9042). The worker tracks dispute status solely via this token.
Q6: Can a digital webpage record be legally valid in a wage dispute?
Yes. Under Section 17 of the Inter-State Migrant Workmen Act 1979, written muster rolls and wage slips serve as admissible evidence before " "Labour Courts. Our CSS @media print engine formats screen records into physical paper balance slips complete with signature lines and QR codes.
Q7: Did you use any paid tools, UI libraries, or external APIs?
Zero. The entire application is 100% free-tier native. Pure HTML5, CSS3 Grid/Flexbox, modular ES6+ JavaScript, native browser speech synthesis, " "local web storage, and hosted permanently on GitHub Pages static CDN for Rs. 0.
Q8: How does the app work offline when there is no internet on a construction site?
We implemented a Progressive Web App Service Worker (sw.js) using a Network-First strategy with automated cache purging (v4.0). Core assets (HTML, CSS, JS, manifest) are cached " "locally during install. Fetch events are intercepted and served from cache when no internet connection is detected.
Q9: What happens if a contractor disputes the hours or wages recorded on the slip?
The slip format includes two signature lines: one for the worker and one for the contractor/munshi. By printing and having the contractor " "sign or countersign daily or weekly advances, it converts informal day labor into documented contractual evidence.
Q10: What security measures prevent Cross-Site Scripting (XSS) in user inputs?
In both js/wageTracker.js and js/complaints.js, every user string (contractor name, site, remarks) passes through our custom escapeHTML() " "sanitizer before being inserted into the DOM. This converts characters like <, >, &, and quotes into safe HTML entities, neutralizing XSS attacks.
Q11: What is the storage limit of localStorage, and what happens if it fills up?
Browser localStorage provides approximately 5 MB of string storage per origin. Because our JSON records are extremely lightweight " "(~250 bytes per work entry), 5 MB can store over 20,000 days of work entries—representing over 50 years of daily logging for a worker.
Q12: How is the alphanumeric Ticket ID (#SH-XXXX) generated?
In js/complaints.js, the generateTicketId() function uses Math.floor(1000 + Math.random() * 9000) prepended with '#SH-'. In a full cloud " "deployment, this would map to a UUIDv4 cryptographic hash to eliminate collision probability across millions of users.
Q13: Why did you choose an English-first interface with bracketed Hindi translations?
Research indicates that while migrant workers speak regional dialects (Bhojpuri, Maithili, Hindi), younger second-generation workers and " "labor union helpers frequently operate phones with English system locales. Combining prominent English terms with immediate bracketed Hindi " "(e.g. 'Wage Ledger (Khata)') ensures universal accessibility across diverse literacy levels without requiring bulky page reloads.
Q14: What specific laws protect migrant laborers under Indian jurisdiction?
Four landmark acts protect them: (1) Minimum Wages Act 1948 (mandates statutory wage floors); (2) Inter-State Migrant Workmen Act 1979 " "(mandates written passbooks and travel allowances); (3) Building and Other Construction Workers (BOCW) Act 1996 (regulates safety and welfare funds); " "and (4) Code on Wages 2019 (universalizes minimum wage floors across all sectors).
Q15: How does the contractor vetting directory calculate timely payment scores?
In js/complaints.js, community ratings are aggregated using a weighted arithmetic mean: (Existing Rating * Total Reviews + New Rating) / (Total Reviews + 1). " "Timely payment percentages are computed dynamically based on the proportion of positive wage clearance feedback.
Q16: How does the Speech Narrator handle browsers that lack Hindi voice engines?
In js/speech.js, initVoices() implements graceful fallback logic. It first searches for 'hi-IN' or 'hi_IN' voices. If absent on a desktop OS, " "it falls back to 'en-IN' (Indian English) or standard English synthesis so speech playback never crashes or remains silent.
Q17: Why did you implement CSS Flexbox and Grid rather than Bootstrap or Tailwind?
Bootstrap and Tailwind introduce 80–150 KB of stylesheet bloat and require preprocessors or external CDN calls. Modern CSS3 natively provides " "Grid and Flexbox. Writing our own bespoke CSS tokens gives us 100% control over touch targets (>=48px), contrast modes, and zero external downloads.
Q18: What is the purpose of the 'Inspector View' button in the Whistleblower tab?
The Inspector View simulates the District Labour Commissioner's administrative dashboard. It proves to examiners that our client-side " "architecture sanitizes identities before storage, showing how enforcement officials review anonymous muster violations and dispatch show-cause notices.
Q19: Why are touch targets sized to at least 48px?
Under WCAG 2.1 AA Accessibility criteria, touch targets must be at least 48x48 CSS pixels. Construction laborers have calloused, dusty hands " "and often use low-cost smartphones with imprecise touch digitizers. Sizing all buttons to >=48px prevents missed taps and accidental clicks.
Q20: How does the High-Contrast mode function under direct sunlight?
Direct sunlight washes out standard mobile LCD screens. Our High-Contrast mode toggles a .high-contrast class on document.body, switching to " "a pure black background (#000000) with ultra-vibrant neon amber (#ea580c), emerald (#4ade80), and white (#ffffff) borders for maximum outdoor clarity.
Q21: How does your Service Worker handle cache updates when you release new code?
In sw.js, we define a cache version token: const CACHE_NAME = 'shramstambh-v1.0'. When updating code, changing the version string causes " "the activate event to delete outdated caches and immediately claim clients via self.clients.claim().
Q22: If a professor asks: 'Can you show me where the wage math is calculated right now?'
Answer confidently: 'Yes, Professor. In js/wageTracker.js at line 143, inside addRecord(), the system calculates: balance = Math.max(0, wage - advance). " "Then status is dynamically set: status = balance === 0 ? "Paid" : "Due".'
Q23: How would you scale Shram Stambh to millions of workers across India?
We would maintain the client-side PWA architecture for offline logging, but add end-to-end encrypted synchronization to a decentralized " "cloud ledger when connectivity becomes available. Workers would authenticate using Aadhaar-linked OTP or decentralized zero-knowledge IDs.
Q24: What is the 14434 helpline number integrated in the header?
14434 is the official Government of India National Labour Helpline launched by the Ministry of Labour and Employment to provide multi-lingual " "assistance and register grievances for unorganized construction and migrant workers across 11 Indian languages.
Q25: What happens if two records are added on the same date with different contractors?
The system supports multiple daily entries. Each record receives a unique timestamp identifier: 'REC-' + Date.now().toString().slice(-6), " "allowing workers who perform separate half-day shifts for different contractors to track each balance independently.
Q26: Why is there an inline SVG QR code on the printable slip instead of an image file?
An image file requires an external image asset or CDN request, which breaks when the phone is offline. Our inline SVG QR code is rendered " "purely via XML markup embedded in the DOM, guaranteeing that printable slips render with 100% fidelity even with zero network connectivity.
